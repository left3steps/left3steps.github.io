01

1. 번호를 제시한 거래와 자진발급 거래부터 나눈다

첫 질문은 ‘내가 어떤 번호로 발급을 요청했는가’입니다. 국세청은 현금영수증을 발급받을 때 이용한 휴대전화번호·카드번호 등의 발급수단이 등록되어 있지 않으면 사용내역이 정상적으로 귀속되지 않을 수 있다고 설명합니다. 휴대전화번호를 알려 주었다는 사실만으로 홈택스의 발급수단 등록까지 끝났다고 가정하지 마세요. 우선 결제 당시 제시한 번호와 등록된 발급수단이 맞는지 확인합니다.

번호를 제시하지 않고 받은 영수증은 다른 질문이 필요합니다. 국세청의 자진발급 안내는 가맹점이 지정 코드인 010-000-1234로 현금영수증을 발급한 경우를 설명합니다. 이 코드로 발급된 영수증은 본인 휴대전화번호로 발급된 영수증과 구별해서 살펴봐야 합니다. 종이에 금액이 인쇄되어 있다는 이유만으로 자진발급분이라고 판단하지 말고, 현금영수증 발급 사실과 표시된 정보를 확인하세요.

예를 들어 본인 번호를 제시했고 그 번호로 발급된 것이 확인된다면, 먼저 발급수단 등록 상태를 살펴볼 차례입니다. 반대로 지정 코드로 자진발급된 것이 확인된다면, 거래별 정보를 준비해 자진발급분 소비자등록 안내를 읽습니다. 단순 구매 영수증이나 계좌이체 확인증만 있고 현금영수증 발급 여부가 불분명하다면, 두 등록 경로 중 하나를 임의로 선택하지 말고 가맹점에 먼저 물어보세요.

02

2. 본인 번호로 발급받았다면 발급수단 등록을 확인한다

국세청 FAQ가 안내하는 경로는 ‘홈택스 → 계산서·영수증·카드 → 현금영수증(근로자·소비자) → 소비자 발급수단·전용카드 → 현금영수증 발급용 휴대전화번호/카드관리’입니다. 홈택스에 직접 접속해 로그인한 뒤 해당 기능에서 등록된 발급수단을 확인하세요. 메뉴 구성이 다르게 보이면 기능명을 기준으로 현재 안내를 찾습니다. 오래된 화면 캡처와 위치가 다르다는 이유만으로 임의의 비슷한 메뉴에서 변경하지 않습니다.

확인할 것은 ‘등록된 번호가 있다’에서 끝나지 않습니다. 실제 영수증 발급에 이용한 번호와 등록된 번호가 같은지 대조해야 합니다. 결제할 때 어떤 번호를 제시했는지 기억이 불분명하다면 영수증과 가맹점의 발급 기록으로 확인할 질문을 정리하세요. 홈택스 로그인에 사용하는 정보와 현금영수증 발급수단 등록은 구별해 확인해야 할 항목입니다.

해당 발급수단이 미등록이라면 공식 화면의 안내에 따라 본인이 사용하는 수단을 등록하고 결과를 확인합니다. 등록 전에는 어떤 번호가 빠져 있었는지, 등록 후에는 무엇을 확인했는지 간단히 메모해 두면 다음 문의가 쉬워집니다. 잘못 입력되어 다른 사람에게 귀속된 거래까지 이 과정으로 해결된다고 생각하지 마세요. 그 경우는 미등록 발급수단 확인과 다른 문제이므로 가맹점과 국세청에 별도 확인이 필요합니다.

03

3. 자진발급 영수증은 금액·승인번호·발급일을 준비한다

지정 코드로 자진발급된 현금영수증이 확인되었다면 국세청 FAQ가 안내하는 세 가지 입력 정보를 준비합니다. 금액, 승인번호, 발급일입니다. 영수증의 주문번호나 쇼핑몰 결제번호를 승인번호로 대신 적지 말고, 현금영수증 거래를 식별하는 항목을 읽어야 합니다. 숫자가 흐리거나 일부가 잘렸다면 추측해 채우기보다 가맹점에 해당 영수증의 정보를 확인하세요.

등록 경로는 ‘홈택스 → 계산서·영수증·카드 → 현금영수증(근로자·소비자) → 근로자·소비자 조회/변경 → 현금영수증 자진발급분 소비자등록’으로 안내되어 있습니다. 현재 화면의 설명에 맞추어 준비한 세 정보를 입력하고, 조회 결과가 본인의 실제 거래와 맞는지 살펴본 뒤 등록 절차를 진행합니다. 단순히 번호를 입력했다는 사실과 등록이 완료되었다는 결과를 구분해 확인하세요.

입력 전에 아래 다섯 항목을 한 번 대조하면 잘못된 거래를 조회하거나 같은 거래를 반복 처리하는 일을 줄일 수 있습니다. 여러 장을 정리할 때는 한 거래마다 영수증과 입력 정보를 한 묶음으로 두고, 확인 결과를 ‘정보 준비’, ‘등록 결과 확인’, ‘문의 필요’ 정도로 구분해 적어 보세요. 이는 개인 점검용 기록이며 국세청의 신고 서식이나 공제 판정표를 대신하지 않습니다.

04

4. 조회·등록 결과가 맞지 않으면 거래별로 질문한다

등록 안내를 따라 했는데 결과가 맞지 않는다면 같은 정보를 여러 번 넣기 전에 어느 단계에서 막혔는지 기록하세요. 입력 정보를 확인할 수 없는지, 조회된 거래가 본인 영수증과 다른지, 등록 결과를 확인하지 못한 것인지에 따라 질문이 달라집니다. 이 글은 모든 거래가 즉시 사용내역에 나타난다고 보장하지 않습니다. 반영 안내와 오류 메시지는 현재 홈택스 화면에서 확인하고, 해결되지 않으면 국세청 상담 창구에 문의하세요.

가맹점에는 ‘현금으로 결제했는데 안 보여요’보다 ‘이 영수증이 본인 번호로 발급된 것인지, 지정 코드로 자진발급된 것인지 확인하고 싶습니다’처럼 발급 사실을 좁혀 물어볼 수 있습니다. 승인번호나 발급일이 읽히지 않는 경우에는 해당 정보를 확인해 달라고 요청하세요. 실제로 현금영수증이 발급되지 않은 경우라면 자진발급분 등록을 반복하는 것이 해결책은 아닙니다. 미발급 관련 절차의 대상·증빙·기한은 별도의 공식 안내를 읽어야 합니다.

다른 사람의 영수증, 가족 명의의 거래, 사업상 지출증빙 목적의 거래가 섞여 있다면 일단 이번 점검 대상과 분리합니다. 본인 사용내역에 보이게 만드는 작업이 명의 변경이나 가족 사용분 합산 자격을 판단하는 작업은 아닙니다. 마지막으로 등록 결과가 확인된 영수증은 다시 입력하지 않도록 구별해 보관하고, 공제 여부가 궁금할 때는 해당 귀속연도의 국세청 안내로 넘어가세요. 기록 연결을 확인하는 단계와 세금 적용을 판단하는 단계를 나누는 것이 마무리입니다.
