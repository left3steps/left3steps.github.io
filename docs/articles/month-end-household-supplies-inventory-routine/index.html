월말 20분, 생활소모품을 중복 구매하지 않는 재고 확인 루틴

휴지, 세제, 쓰레기봉투처럼 자주 쓰는 생활소모품은 집에 남은 양을 기억으로 판단하면 같은 물건을 또 사기 쉽습니다. 월말 20분 동안 보관 위치와 다음 확인일까지 필요한 양만 기록하는 방법입니다.

01

처음 4분, 확인할 품목을 다섯 종류 안으로 제한한다

생활소모품을 전부 세려고 하면 욕실과 주방을 오가다 시간이 끝납니다. 먼저 최근 한 달 사이에 부족해서 급히 샀거나, 이미 있는데 또 산 품목을 떠올립니다. 화장지, 쓰레기봉투, 세탁세제, 주방세제, 청소용 천처럼 사용 빈도가 높은 것 가운데 다섯 종류만 오늘의 확인 목록에 적습니다.

목록 옆에는 각 품목의 기본 보관 위치를 한 곳씩 씁니다. 실제 물건이 여러 방에 흩어져 있어도 새 제품을 먼저 모아 두는 기준 위치가 있으면 전체 수량을 파악하기 쉬워집니다. 이번 확인에서는 수납장을 새로 정리하지 않고, 어디에 몇 군데로 나뉘어 있는지만 표시합니다.

바로 해보기
  • 최근 급히 샀거나 중복 구매한 품목을 골랐는가
  • 오늘 확인할 대상을 다섯 종류 안으로 줄였는가
  • 각 품목의 기본 보관 위치를 한 곳씩 적었는가
  • 개봉한 것과 미개봉 제품을 구분했는가
  • 다음 확인일까지 필요한 양만 판단했는가
02

다음 6분, 개수보다 ‘사용 중’과 ‘대기 중’을 나누어 본다

각 보관 위치를 돌며 현재 사용 중인 것과 아직 개봉하지 않은 것을 구분합니다. 세제처럼 용기 안의 양을 정확히 재기 어려운 품목은 ‘절반 이상’, ‘절반 미만’처럼 두 단계로만 기록해도 됩니다. 제품을 다른 용기에 옮기거나 포장을 열지 않고 겉에서 확인할 수 있는 범위만 봅니다.

여러 장소에서 같은 제품이 나오면 한곳으로 당장 옮기기보다 목록에 위치를 함께 씁니다. 예를 들어 화장지 미개봉 묶음은 다용도실, 낱개는 욕실이라고 적으면 다음에 어디부터 확인할지 분명해집니다. 수량이 아니라 사용 순서를 정하는 기록이므로 정확한 숫자를 세는 데 시간을 쓰지 않습니다.

03

가운데 5분, 구매 기준을 ‘다음 확인일까지 충분한가’로 바꾼다

남은 양을 본 뒤 다음 재고 확인일을 달력에 먼저 정합니다. 그날까지 사용할 대기 제품이 있다면 구매 목록에서 빼고, 사용 중인 한 개만 남아 다음 확인 전 떨어질 가능성이 큰 품목만 후보로 표시합니다. 할인 여부나 대용량 포장보다 집에 이미 있는 양과 보관할 자리를 먼저 판단합니다.

구매 후보에는 제품명만 적지 말고 필요한 최소 단위를 함께 씁니다. ‘쓰레기봉투 1묶음’, ‘주방세제 리필 1개’처럼 적으면 매장에서 묶음 수를 다시 고민할 일이 줄어듭니다. 특정 제품의 사용량과 보관 방법은 포장 표시를 따르고, 정해 둔 수납 범위를 넘는 양은 목록에 추가하지 않습니다.

04

마지막 5분, 한 줄 목록을 남기고 흩어진 기록을 지운다

확인이 끝나면 품목별 메모를 길게 보관하지 말고 실제로 살 것만 한 줄 목록으로 옮깁니다. 구매하지 않을 품목은 기본 보관 위치만 남기고 수량 기록을 지워도 됩니다. 다음 달에는 지난 숫자를 맞추는 대신 같은 위치를 다시 열어 현재 상태를 새로 확인합니다.

마지막으로 사용 중인 제품이 끝나면 대기 제품을 어디서 꺼낼지 가족이 알 수 있게 합니다. 별도 표지판이 필요 없다면 수납장 안쪽에 품목 이름을 작게 붙이는 정도로 충분합니다. 20분이 지나면 남은 공간을 더 정리하지 않고 종료해야 이 루틴이 월말마다 반복 가능한 크기로 유지됩니다.
